# GPS 속도 로거

휴대폰 GPS로 속도 로우데이터를 수집해 CSV로 내보내는 단일 HTML 앱.
서버·라이브러리·설치 없이 브라우저만으로 동작합니다.

## 사용법

1. 휴대폰 브라우저로 접속
2. `측정 시작` → 위치 권한 허용
3. 이동
4. `측정 종료` → `CSV 저장`

## CSV 컬럼

| 컬럼 | 설명 |
|---|---|
| `seq` | 순번 |
| `datetime` | 로컬 시각 (밀리초까지) |
| `epoch_ms` | UNIX 타임스탬프(ms) |
| `elapsed_s` | 측정 시작 후 경과 초 |
| `lat` / `lon` | 위도 / 경도 |
| `speed_kmh` / `speed_ms` | 속도 (km/h, m/s) |
| `lat_kf` / `lon_kf` | 칼만 평활 좌표 (거리·속도 계산에 실제 사용된 값) |
| `kf_sigma_m` | 칼만 필터 사후 표준편차 |
| `speed_source` | `gps` / `calc` / 필터 사유 |
| `speed_gps_kmh` | 하드웨어(도플러) 속도 원본 |
| `speed_calc_kmh` | 좌표 차분 속도 원본 |
| `seg_dt_s` / `seg_dist_m` | 구간 시간 / 구간 이동거리 |
| `accepted` | 1=거리·속도에 반영됨, 0=필터에서 제외 |
| `reason` | 판정 사유 (`moved`/`jitter_hold`/`min_dt`/`accuracy`/`v_max`/`stationary`) |
| `mode` | `walk` / `car` |
| `accuracy_m` | 위치 오차 반경 |
| `altitude_m` | 고도 |
| `heading_deg` | 방위각 |
| `cum_dist_m` | 누적 주행거리 |

UTF-8 BOM을 포함해 엑셀에서 바로 열립니다.

## 노이즈 필터

GPS 원좌표는 제자리에 서 있어도 수 m~수십 m씩 흔들립니다. 이를 그대로 거리로
누적하면 도보 중에도 80km/h 같은 값이 나옵니다. 이를 막기 위해 4단계를 거칩니다.

1. **정확도 게이트** — `accuracy`가 기준(도보 25m / 차량 40m)을 넘으면 제외
2. **칼만 필터** — 측정 정확도를 신뢰도로 삼아 좌표를 평활
3. **구간 게이트** — 최소 시간 미만이거나, 이동거리가 노이즈 수준이면 이동으로 보지 않음
4. **상한 클램프** — 모드별 물리적 상한(도보 25 / 차량 250 km/h) 초과값 폐기

제외된 포인트도 CSV에는 **그대로 남습니다.** `accepted`/`reason` 컬럼으로 구분되므로
원본 로우데이터를 잃지 않고 엑셀에서 직접 재계산할 수 있습니다.

### 검증 (시뮬레이션)

| 시나리오 | 실제 | 측정 |
|---|---|---|
| 제자리 ±9m 흔들림 20회 | 0 km/h, 0 m | 0.0 km/h, 0 m |
| 도보 (1.3 m/s, 정확도 ±8m) | 4.7 km/h, 78 m | 4.9 km/h, 60 m |
| 주행 (13.9 m/s, 정확도 ±15m) | 50.0 km/h, 834 m | 53.2 km/h, 782 m |

거리가 다소 과소 집계되는 것은 칼만 필터의 지연 때문이며, 속도 정확도를 위해
의도적으로 감수한 트레이드오프입니다.

## 알아둘 점

- **HTTPS 필수** — `file://`이나 `http://`에서는 브라우저가 위치 권한을 주지 않습니다.
- **화면이 꺼지면 수집이 멈춥니다.** WakeLock으로 방지하지만 미지원 기기가 있습니다. 백그라운드 장시간 수집은 네이티브 앱이 필요합니다.
- **샘플링 간격이 균일하지 않습니다.** GPS 수신 상황에 따라 달라지므로, 정확한 1Hz가 필요하면 `epoch_ms` 기준으로 후처리 리샘플링하세요.
- 정지 상태에서는 하드웨어 속도값이 `null`로 오는 경우가 많아 좌표 차분값으로 대체됩니다 (`speed_source=calc`).
- **측정 시작 후 첫 30초 정도는 GPS와 칼만 필터가 수렴하는 구간**이라 값이 불안정합니다.
- 실내·건물 사이·터널에서는 정확도가 급격히 나빠져 대부분의 포인트가 제외됩니다.
