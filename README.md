# GPS 속도 로거

휴대폰 GPS로 속도 로우데이터를 수집해 CSV로 내보내는 단일 HTML 앱.
서버·라이브러리·설치 없이 브라우저만으로 동작합니다.

## 사용법

1. 휴대폰 브라우저로 접속
2. `측정 시작` → 위치 권한 허용
3. 이동
4. `측정 종료` → `CSV 저장`

## CSV 컬럼

| 컬럼 | 설명 |
|---|---|
| `seq` | 순번 |
| `datetime` | 로컬 시각 (밀리초까지) |
| `epoch_ms` | UNIX 타임스탬프(ms) |
| `elapsed_s` | 측정 시작 후 경과 초 |
| `lat` / `lon` | 위도 / 경도 |
| `speed_kmh` / `speed_ms` | 속도 (km/h, m/s) |
| `lat_kf` / `lon_kf` | 칼만 평활 좌표 (거리·속도 계산에 실제 사용된 값) |
| `kf_sigma_m` | 칼만 필터 사후 표준편차 |
| `fix_type` | `gnss` / `network` / `unknown` — 측위 방식 |
| `state` | `move` / `stop` / `nofix` |
| `speed_source` | `doppler` / `window` / 정지·폐기 사유 |
| `doppler_kmh` | 하드웨어 도플러 속도 원본 |
| `win_net_m` / `win_path_m` | 윈도우 순이동 / 경로길이 |
| `win_straightness` | 직진도 |
| `speed_gps_kmh` | 하드웨어(도플러) 속도 원본 |
| `seg_dt_s` / `seg_dist_m` | 구간 시간 / 구간 이동거리 |
| `accepted` | 1=거리·속도에 반영됨, 0=필터에서 제외 |
| `reason` | 판정 사유 (`moved`/`jitter_hold`/`min_dt`/`accuracy`/`v_max`/`stationary`) |
| `mode` | `walk` / `car` |
| `accuracy_m` | 위치 오차 반경 |
| `altitude_m` | 고도 |
| `heading_deg` | 방위각 |
| `cum_dist_m` | 누적 주행거리 |

UTF-8 BOM을 포함해 엑셀에서 바로 열립니다.

## 속도 산출 원리

**속도의 1차 출처는 GNSS 도플러 속도(`coords.speed`)입니다.** 위성 신호의 주파수
편이에서 직접 얻는 값이라, 위치 정확도가 20m여도 속도는 ±0.05m/s 수준으로
정확합니다. 내비게이션이 쓰는 값이 이것입니다.

좌표 차분(Δ거리/Δ시간)은 **위치 오차를 그대로 속도로 증폭**시킵니다. ±20m 오차가
1초 간격이면 72km/h가 됩니다. 실내에서 위성이 안 잡혀 WiFi 측위로 폴백되면
좌표가 수십 m씩 점프하므로 이 값은 무의미합니다.

### 엄격 모드 (기본값)

도플러 속도가 없으면 **속도를 산출하지 않습니다.** 실내에서 내비가 0을 띄우는 것과
같은 동작입니다.

### 측위 방식 판별

GNSS 수신기는 고도·방위·속도를 함께 냅니다. 이 셋이 모두 없고 정확도가 나쁘면
WiFi/기지국 삼각측량이며, 화면에 **「GPS 미확보 — 네트워크 측위」**로 표시하고
속도를 계산하지 않습니다.

### 직진도 판별 (허용 모드)

2점 비교로는 흔들림과 이동을 구분할 수 없습니다. 시계열 윈도우로 판단합니다.

```
직진도 = 순이동거리(처음→끝 직선) / 경로길이(구간 합)
```

| | 경로길이 | 순이동 | 직진도 |
|---|---|---|---|
| GPS 흔들림(랜덤워크) | 큼 | ≈0 | **0.1~0.4** |
| 실제 이동 | 큼 | 큼 | **0.9~1.0** |

흔들림은 제자리를 맴돌아 순이동이 상쇄되지만, 실제 이동은 한 방향으로 누적됩니다.
평활 좌표 기준으로 계산해야 판별력이 나옵니다(원좌표는 노이즈가 경로길이를 부풀림).

정지↔이동 전환에는 **히스테리시스**(이동 진입 2회 연속, 정지 복귀 3회 연속)를 걸어
깜빡임을 막습니다. 정지 상태에서는 속도가 **무조건 0**이고 거리도 누적되지 않습니다.

## 알아둘 점

- **HTTPS 필수** — `file://`이나 `http://`에서는 브라우저가 위치 권한을 주지 않습니다.
- **화면이 꺼지면 수집이 멈춥니다.** WakeLock으로 방지하지만 미지원 기기가 있습니다. 백그라운드 장시간 수집은 네이티브 앱이 필요합니다.
- **샘플링 간격이 균일하지 않습니다.** GPS 수신 상황에 따라 달라지므로, 정확한 1Hz가 필요하면 `epoch_ms` 기준으로 후처리 리샘플링하세요.
- 정지 상태에서는 하드웨어 속도값이 `null`로 오는 경우가 많아 좌표 차분값으로 대체됩니다 (`speed_source=calc`).
- **측정 시작 후 첫 30초 정도는 GPS와 칼만 필터가 수렴하는 구간**이라 값이 불안정합니다.
- 실내·건물 사이·터널에서는 정확도가 급격히 나빠져 대부분의 포인트가 제외됩니다.
