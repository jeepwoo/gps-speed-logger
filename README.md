# GPS 속도 로거

휴대폰 GPS로 속도 로우데이터를 수집해 CSV로 내보내는 단일 HTML 앱.
서버·라이브러리·설치 없이 브라우저만으로 동작합니다.

## 사용법

1. 휴대폰 브라우저로 접속
2. `측정 시작` → 위치 권한 허용
3. 이동
4. `측정 종료` → `CSV 저장`

## CSV 컬럼

| 컬럼 | 설명 |
|---|---|
| `seq` | 순번 |
| `datetime` | 로컬 시각 (밀리초까지) |
| `epoch_ms` | UNIX 타임스탬프(ms) |
| `elapsed_s` | 측정 시작 후 경과 초 |
| `lat` / `lon` | 위도 / 경도 |
| `speed_kmh` / `speed_ms` | 속도 (km/h, m/s) |
| `speed_source` | `gps`(하드웨어 측정) / `calc`(좌표 차분) / `none` |
| `accuracy_m` | 위치 오차 반경 |
| `altitude_m` | 고도 |
| `heading_deg` | 방위각 |
| `cum_dist_m` | 누적 주행거리 |

UTF-8 BOM을 포함해 엑셀에서 바로 열립니다.

## 알아둘 점

- **HTTPS 필수** — `file://`이나 `http://`에서는 브라우저가 위치 권한을 주지 않습니다.
- **화면이 꺼지면 수집이 멈춥니다.** WakeLock으로 방지하지만 미지원 기기가 있습니다. 백그라운드 장시간 수집은 네이티브 앱이 필요합니다.
- **샘플링 간격이 균일하지 않습니다.** GPS 수신 상황에 따라 달라지므로, 정확한 1Hz가 필요하면 `epoch_ms` 기준으로 후처리 리샘플링하세요.
- 정지 상태에서는 하드웨어 속도값이 `null`로 오는 경우가 많아 좌표 차분값으로 대체됩니다 (`speed_source=calc`).
